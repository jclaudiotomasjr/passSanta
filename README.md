
# PassSanta

Aplicação desenvolvida em Go para facilitar o gerenciamento e a recuperação rápida de senhas utilizadas no dia a dia operacional.

O objetivo da ferramenta é permitir que o usuário selecione uma senha pré-configurada, conecte no SAP GUI ou copie automaticamente para a área de transferência e a utilize em processos de autenticação sem a necessidade de digitação manual.

## Funcionalidades

- Exibição de senhas pré-configuradas.
- Cópia automática para a área de transferência.
- Interface simples via terminal.
- Execução rápida e leve.
- Desenvolvido em Golang.

## Requisitos

- Go 1.20 ou superior
- Windows 10 ou superior
